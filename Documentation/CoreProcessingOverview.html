Startup
System Initialization
CoreInitializer boots all subsystems — memory, tools, cognitive processors — and spawns the continuous async loop.
Loop Guard
[Stop] Shutdown flag — loop exits    [Skip] Processing lock held or cooldown active
[Pass] All clear — lock acquired, cycle proceeds
Context
Build Thought Context
Assembles the full cognitive state: memory tiers, tool state, session files, active goals, and user context.
Processing Mode Selection
[Reactive] Unprocessed events in buffer    [Proactive] Idle <6 min    [Reflective] Idle >=6 min
Reactive
ReactiveConstructor
Responds to user input or tool results
Proactive
ProactiveConstructor
Self-initiated thought when idle
Reflective
ReflectiveConstructor
Deep reflection after extended idle
LLM Call
Ollama — Generate Thought
LLM produces a structured response containing a next-mode directive, a speak flag, optional tool actions, and thought content stored to the buffer.
Actions Requested?
[Yes] Tool actions present — execute pipeline, inject result to buffer, then continue
[No] No actions — proceed directly to Speak Gate
Tool Execution
ToolManager — Execute Actions
Resolves each action to an active BaseTool, runs execute(), and feeds the result back into the ThoughtBuffer for the ActionConstructor to process.
Speak Gate — Should Anna Respond?
[Block] speak=NO, rate limit hit, or interval too short — suppressed
[Pass] speak=YES and rate OK — proceed to SpeakJudge for LLM veto
LLM Call
SpeakJudge + Generate Response
A secondary LLM call vetoes low-value speech. If approved, ResponsiveConstructor generates the final response text with full memory context injected.
CognitiveFilter — Validate Response
[Pass] Context, language, and duplicate checks all clear
[Discard] Off-topic, wrong language, or duplicate — silently dropped
[Fail-open] Filter timeout — response approved automatically
Output
Deliver Response
Dispatches to all active channels simultaneously: TTS voice output, GUI callback, Discord DM, and group chat broadcast. Response echoed back to ThoughtBuffer as [SELF].
Memory
Persist to Memory
Response saved to short-term memory. Embedded entries written to medium-term. Long-term daily summaries updated periodically. All files AES-256-GCM encrypted.
Cycle End
Yield & Reset
Anti-spin sleep(0.1s) yields the event loop. Periodic stats and memory integration run every 5 minutes. Crash recovery resets if stable for 5+ minutes.
[Loop]
Returns to Loop Guard — next cycle begins
Background services — running concurrently on every cycle
Tool Context Loops
Per-tool async tasks
Active tools push periodic updates into the ThoughtBuffer independently of the main loop.
Memory Integration
Long-memory search
Similarity search over long-term memory every ~5 min — relevant entries injected as thought events.
