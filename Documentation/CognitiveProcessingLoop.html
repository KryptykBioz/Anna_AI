Session / file
4-tier
overview
Tier 1 — Short Memory
last 25 messages · not embedded · always in context
Tier 2 — Medium Memory
today's older messages · embedded · searchable
Tier 3 — Long Memory
daily diary summaries · embedded · searchable
Tier 4 — Base Knowledge
read-only docs · personality embeddings · game guides
Tiers 1–3 stored as AES-256-GCM encrypted JSON. Tier 4 is read-only flat files + pre-built embedding JSONs (nomic-embed-text).
