# PREREQUISITES:
# ============================================================================

# 4. Visual Studio Build Tools (if building PyAudio from source)
#
# ============================================================================
# INSTALLATION ORDER FOR NEW AGENTS:
# ============================================================================
#
# STEP 1: Create virtual environment
# If Python 3.11 is installed and in PATH:
# py -3.11 -m venv venv
# or
# python3.11 -m venv venv
# If that doesn't work, use the full path:
# C:\Python311\python.exe -m venv venv
# To find your Python 3.11 installation path:
# py -3.11 -c "import sys; print(sys.executable)"
#
# STEP 2: Activate the virtual environment (from project root)
# .\venv\Scripts\activate
#
# STEP 2.5: Upgrade pip
# python -m pip install --upgrade pip
#
# STEP 3: Install this requirements file
# pip install -r requirements.txt
#
# STEP 4: CRITICAL - Install specific transformers version
# pip install transformers==4.38.2
# (Newer versions break XTTS - DO NOT upgrade beyond 4.38.2)
#
# STEP 5 (Only for 50-series GPU support): Copy GPU packages from Anna_AI (DO NOT use pip for these)
# Use copy_gpu_packages.py script OR manual copy from SETUP.md
# Required packages to copy:
#   - torch/ and torch-*.dist-info/
#   - torchaudio/ and torchaudio-*.dist-info/
#   - torchvision/ and torchvision-*.dist-info/
#   - nvidia*/ (ALL nvidia folders - contains CUDA libraries)
#   - ctranslate2/ and ctranslate2-*.dist-info/ (CRITICAL for Whisper)
#   - pyaudio/ and PyAudio-*.dist-info/ (if custom-built)
#
# STEP 6 (Only for 50-series GPU support): Verify GPU support
# python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}')"
# python -c "from faster_whisper import WhisperModel; print('CTranslate2: OK')"
#
# STEP 7: Test with GUI
# .\START.bat
#
# ============================================================================
# WHY NOT USE PIP FOR GPU PACKAGES?
# ============================================================================
# RTX 50-series (Blackwell/sm_120) is NOT officially supported by PyPI.
# Anna_AI has custom-built PyTorch with sm_120 support that MUST be copied
# directly. Using pip install will give you CPU-only or incompatible builds.
#
# See SETUP.md for detailed explanation and troubleshooting.
#
